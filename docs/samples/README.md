# サンプル要件定義書

レビュー機能をお試しいただくためのサンプル要件定義書です。
これらのサンプルには**意図的にヌケモレや問題を含めています**。

---

## 📄 サンプル一覧

### 1. タスク管理システム（小規模）
**ファイル**: [01-task-management.md](01-task-management.md)

**概要**: チーム向けのシンプルなタスク管理システムの要件定義書

**規模**: 約100行、小規模

**主な問題点**:
- 🔴 パスワードポリシーが未定義
- 🔴 エラーハンドリングの記載なし
- 🔴 バックアップ・リカバリの記載なし
- 🟡 "速く"、"適切に"などの曖昧な表現
- 🟢 定量化されていない非機能要件

**推奨用途**: 初めてレビュー機能を試す方向け

---

### 2. ECサイトシステム（大規模）
**ファイル**: [02-ecommerce-large.md](02-ecommerce-large.md)

**概要**: 本格的なオンラインショッピングモールの要件定義書

**規模**: 約800行、大規模（約16,000文字）

**機能範囲**:
- 顧客向け機能（会員登録、商品閲覧、カート、注文、レビューなど）
- 管理者向け機能（商品管理、在庫管理、注文管理、売上管理など）
- 20以上の画面定義
- 詳細なデータモデル

**主な問題点**:
- 🔴 **パスワードポリシーの詳細不足**
  - 最小文字数なし
  - 複雑さ要件なし
  - 有効期限なし

- 🔴 **セッション管理の詳細が不明**
  - タイムアウト時間なし
  - 並行ログインの扱い不明

- 🔴 **エラーハンドリングの詳細不足**
  - ネットワークエラー時の挙動不明
  - バリデーションエラーの表示方法不明

- 🔴 **バックアップ戦略が曖昧**
  - 頻度が不明
  - 保存期間が不明
  - リカバリ手順の詳細なし

- 🔴 **ログ管理の詳細不足**
  - 保存期間が不明
  - ログの種類が不明確

- 🔴 **API認証方式の記載なし**
  - 外部システム連携時の認証方法が不明

- 🔴 **データ保持期間の記載なし**
  - 個人情報の保持期間
  - ログの保持期間
  - 注文履歴の保持期間

- 🟡 **セキュリティ対策の具体性不足**
  - "実施する"とあるが具体的な手法が不明
  - 脆弱性診断の頻度なし

- 🟡 **監視方法の詳細不明**
  - 監視ツールの指定なし
  - アラート条件が不明

- 🟡 **パフォーマンス目標の一部が曖昧**
  - "対応する"などの表現

- 🟢 **ファイルサイズ・形式制限なし**
  - 商品画像のサイズ・形式制限
  - レビュー画像の制限

- 🟢 **通知方法の詳細不足**
  - メール送信失敗時のリトライ戦略なし

- 🟢 **アクセス権限の詳細が不十分**
  - 管理者権限の詳細な定義が不足

**推奨用途**:
- 大規模システムのレビュー体験
- AIのレビュー能力の限界テスト
- 複雑な要件定義書の問題検出

## 💡 Tips

### レビュー結果の活用方法

1. **指摘事項の優先度で分類**
   - High（重大）: すぐに対応が必要
   - Medium（中程度）: 計画的に対応
   - Low（軽微）: 余裕があれば対応

2. **カテゴリ別に対応**
   - 漏れ: 不足している要件を追加
   - 矛盾: 整合性を確認して修正
   - 曖昧: 具体的な表現に書き換え
   - 品質: 読みやすさ・保守性の向上

3. **改善提案を参考に修正**
   - AIが提示する具体的な改善案を参考にする
   - 同様の問題が他の箇所にもないかチェック
