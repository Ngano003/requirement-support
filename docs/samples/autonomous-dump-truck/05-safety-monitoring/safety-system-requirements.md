## 1. はじめに

### 1.1 文書の目的

本文書は、自律移動ダンプカーシステムにおける安全監視サブシステムの詳細要件を定義する。安全監視サブシステムは、車両周辺の安全を監視し、衝突リスクを検出し、必要に応じて緊急停止などの介入を実行する。

### 1.2 適用範囲

本要件定義書は、以下の機能に適用される：

- 衝突リスク評価
- 前方衝突回避
- 側方・後方衝突警告
- 緊急停止制御
- 安全状態監視
- フェールセーフ制御

## 2. 機能要件

### 2.1 衝突回避機能

#### 2.1.1 前方衝突回避

**SAFE-REQ-001: 前方障害物検出**
- システムは、前方の障害物を検出しなければならない
- 検出範囲：前方120m
  ← ★矛盾：マスターでは前方100m
- 検出周期：50ms以内
- 優先度：最高

**SAFE-REQ-002: TTC（衝突予測時間）計算**
- システムは、前方障害物との衝突予測時間（Time To Collision）を計算しなければならない
- 計算式：TTC = (相対距離) / (相対速度)
- 更新周期：50ms
- 優先度：最高

**SAFE-REQ-003: 衝突回避介入**
- システムは、TTC閾値を下回った場合、衝突回避介入を実行しなければならない
- 介入閾値：
  - TTC < 5秒：警告出力
  - TTC < 3秒：減速指令
  - TTC < 1.5秒：緊急ブレーキ
    ← ★矛盾：マスターおよび車両制御では2秒
- 優先度：最高

**SAFE-REQ-004: 衝突回避減速度**
- 衝突回避時の減速度は、衝突を回避可能な最小減速度でなければならない
- 最大減速度：空荷4.0m/s²、満載2.5m/s²
- 優先度：最高

#### 2.1.2 側方衝突警告

**SAFE-REQ-010: 側方接近物体検出**
- システムは、側方から接近する物体を検出しなければならない
- 検出範囲：側方10m
  ← ★矛盾：マスターでは側方5m
- 検出対象：車両、重機、作業員
- 優先度：高

**SAFE-REQ-011: 側方衝突警告出力**
- システムは、側方衝突リスク検出時に警告を出力しなければならない
- 警告方法：視覚警告（HMI）、聴覚警告（ブザー）
- 警告閾値：接近速度と距離に基づくリスク評価
- 優先度：高

#### 2.1.3 後方衝突警告

**SAFE-REQ-020: 後方障害物検出**
- システムは、後退時の後方障害物を検出しなければならない
- 検出範囲：後方15m
- 最小検出サイズ：30cm x 30cm
- 優先度：高

**SAFE-REQ-021: 後方衝突警告**
- システムは、後方障害物検出時に警告を出力しなければならない
- 警告距離：5m以内
- 優先度：高

### 2.2 緊急停止機能

**SAFE-REQ-100: 緊急停止要求生成**
- システムは、以下の条件で緊急停止要求を生成しなければならない
  - 前方障害物との衝突回避不可能
  - センサー重大故障検出
  - 車両制御系故障検出
  - オペレーターによる緊急停止ボタン押下
- 優先度：最高

**SAFE-REQ-101: 緊急停止指令出力**
- システムは、緊急停止要求を車両制御サブシステムへ送信しなければならない
- 送信遅延：検出から10ms以内
  ← ★矛盾：マスターでは100ms以内
- 優先度：最高

**SAFE-REQ-102: 緊急停止完了確認**
- システムは、緊急停止の完了を確認しなければならない
- 確認条件：車速0km/h、パーキングブレーキ作動
- 優先度：最高

← ★ヌケモレ：緊急停止後の復帰手順が未記載

### 2.3 安全状態監視機能

**SAFE-REQ-200: 安全関連センサー監視**
- システムは、安全に関わるセンサーの状態を監視しなければならない
- 監視対象：
  - 前方LiDAR
  - 前方カメラ
  - 前方レーダー
  - GNSS/IMU
- 監視周期：100ms
- 優先度：最高

**SAFE-REQ-201: センサー故障検出**
- システムは、センサー故障を検出しなければならない
- 検出時間：500ms以内
- 優先度：最高

← ★ヌケモレ：故障検出後の具体的な動作（縮退運転か緊急停止か）が未記載

**SAFE-REQ-202: システム健全性監視**
- システムは、自律走行システム全体の健全性を監視しなければならない
- 監視項目：
  - CPU使用率
  - メモリ使用率
  - プロセス死活監視
  - 通信遅延
- 優先度：高

← ★曖昧：各監視項目の異常閾値が不明

### 2.4 フェールセーフ機能

**SAFE-REQ-300: 縮退運転判定**
- システムは、一部センサー故障時に縮退運転を判定しなければならない
- 優先度：最高

← ★ヌケモレ：縮退運転の具体的な条件（どのセンサーがどの程度故障したら縮退か）が未記載

**SAFE-REQ-301: 縮退運転時の制限**
- システムは、縮退運転時に以下の制限を適用しなければならない
  - 最大速度：10km/h
  - 走行モード：低速直線走行のみ
- 優先度：最高

← ★ヌケモレ：縮退運転からの復帰条件が未記載

**SAFE-REQ-302: 最小リスク状態への遷移**
- システムは、重大故障検出時に最小リスク状態（MRM: Minimal Risk Maneuver）へ遷移しなければならない
- MRM動作：緊急停止、パーキングブレーキ作動、ハザードランプ点灯
- 優先度：最高

### 2.5 作業員安全確保機能

**SAFE-REQ-400: 作業員検出**
- システムは、車両周辺の作業員を検出しなければならない
- 検出範囲：全周30m
- 検出精度：95%以上
- 優先度：最高

**SAFE-REQ-401: 作業員接近時の減速**
- システムは、作業員が10m以内に接近した場合、速度を5km/h以下に制限しなければならない
- 優先度：最高

**SAFE-REQ-402: 作業員接近時の警告**
- システムは、作業員に対して車両の接近を警告しなければならない
- 警告方法：警告音（ホーン）、回転灯
- 優先度：高

← ★ヌケモレ：警告音の音量・周波数、回転灯の色・点滅パターンが未記載

## 3. 性能要件

**SAFE-REQ-500: 衝突リスク評価周期**
- 衝突リスク評価の処理周期は、50ms以内でなければならない
- 優先度：最高

**SAFE-REQ-501: 緊急停止応答時間**
- 緊急停止要求の生成から車両制御への指令送信までの時間は、10ms以内でなければならない
- 優先度：最高

**SAFE-REQ-502: 故障検出時間**
- センサー・システム故障の検出時間は、500ms以内でなければならない
- 優先度：最高

## 4. 非機能要件

### 4.1 安全性要件

**SAFE-REQ-600: 安全度水準**
- 安全監視機能は、ASIL-D相当の安全度を満たさなければならない
- 適用規格：ISO 26262
- 優先度：最高

**SAFE-REQ-601: 独立性**
- 安全監視機能は、他のサブシステムから独立して動作しなければならない
- 独立性確保：専用ECU、専用電源系統
- 優先度：最高

← ★ヌケモレ：専用ECUのスペック、専用電源系統の詳細が未記載

### 4.2 信頼性要件

**SAFE-REQ-610: 誤検出率**
- 障害物検出の誤検出率は、1%以下でなければならない
- 優先度：高

**SAFE-REQ-611: 見落とし率**
- 障害物検出の見落とし率は、0.1%以下でなければならない
- 優先度：最高

## 5. インターフェース要件

### 5.1 入力インターフェース

**SAFE-REQ-700: 障害物情報入力IF**
- センシングサブシステムからの障害物情報入力IF
- プロトコル：ROS 2 Topic
- トピック名：`/sensing/perception/objects`
- 更新周期：20Hz
- 優先度：最高

**SAFE-REQ-701: 自己位置・速度入力IF**
- センシングサブシステムからの自己位置・速度入力IF
- プロトコル：ROS 2 Topic
- トピック名：`/sensing/localization/pose`, `/vehicle/status`
- 更新周期：50Hz
- 優先度：最高

**SAFE-REQ-702: 緊急停止ボタン入力IF**
- オペレーター席の緊急停止ボタン入力IF
- プロトコル：デジタル入力（GPIO）
- 応答時間：10ms以内
- 優先度：最高

### 5.2 出力インターフェース

**SAFE-REQ-710: 緊急停止指令出力IF**
- 車両制御サブシステムへの緊急停止指令出力IF
- プロトコル：ROS 2 Topic（高優先度）、CAN（冗長）
- トピック名：`/safety/emergency_stop`
- CAN ID：0x7FF（最高優先度）
- 優先度：最高

**SAFE-REQ-711: 警告出力IF**
- HMIサブシステムへの警告出力IF
- プロトコル：ROS 2 Topic
- トピック名：`/safety/warnings`
- データ型：`custom_msgs/SafetyWarning`
- 優先度：高

**SAFE-REQ-712: 警報出力IF**
- 警報装置（ホーン、回転灯）への出力IF
- プロトコル：デジタル出力（GPIO）
- 優先度：高

## 6. テスト要件

**SAFE-REQ-800: 衝突回避テスト**
- 衝突回避機能のテストを実施すること
- テストシナリオ：
  - 静止障害物への接近
  - 移動障害物への接近
  - 急な飛び出し
- 優先度：最高

**SAFE-REQ-801: 緊急停止テスト**
- 緊急停止機能のテストを実施すること
- テスト項目：
  - 応答時間測定
  - 停止距離測定
  - フェイルセーフ動作確認
- 優先度：最高

**SAFE-REQ-802: フォールトインジェクションテスト**
- 故障注入試験を実施すること
- 注入故障：
  - センサー故障
  - 通信異常
  - ECU故障
- 優先度：最高
