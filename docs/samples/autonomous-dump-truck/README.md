# 自律移動ダンプカーシステム サンプル要件定義書

## 概要

本ディレクトリには、**建設・採掘現場における自律移動ダンプカーシステム**の要件定義書サンプルが含まれています。

**重要：本要件定義書は、要件レビューAIシステムのテスト用として作成されたものです。意図的に多数の欠陥（ヌケモレ、矛盾、曖昧な表現など）が含まれています。**

---

## プロジェクト概要

### システム名
自律移動ダンプカーシステム（Autonomous Dump Truck: ADT）

### 目的
建設現場や採掘現場において、土砂の積載場所から投下場所までの自律走行を実現し、オペレーターの作業負荷を軽減し、現場の安全性と生産性を向上させる。

### 主要機能
- GNSS/RTK測位による高精度自己位置推定
- LiDAR・カメラ・レーダーによる環境認識
- 動的障害物回避を含む経路計画
- 操舵・速度・ブレーキの自動制御
- 衝突回避・緊急停止などの安全監視
- 運行管理システムとの通信
- 遠隔監視

## 使用目的

本要件定義書サンプルは、以下の目的で使用されることを想定しています：

1. **要件レビューAIシステムのテスト**
   - 要件の矛盾検出
   - ヌケモレ検出
   - 曖昧な表現の検出
   - トレーサビリティの検証

2. **要件定義書の品質評価**
   - 完全性（Completeness）
   - 一貫性（Consistency）
   - 明確性（Clarity）
   - 追跡可能性（Traceability）

3. **教育・トレーニング**

   - レビュー技術の向上
