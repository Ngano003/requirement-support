## 1. はじめに

### 1.1 文書の目的

本文書は、自律移動ダンプカーシステムにおける車両制御サブシステムの詳細要件を定義する。車両制御サブシステムは、経路計画サブシステムから受信した目標経路・速度に追従するよう、操舵、加減速、ブレーキの制御を実行する。

### 1.2 適用範囲

本要件定義書は、以下の機能に適用される：

- 操舵制御（Steering Control）
- 速度制御（Speed Control）
- ブレーキ制御（Brake Control）
- パワートレイン制御（Powertrain Control）
- 緊急停止制御（Emergency Stop Control）
- 車両状態監視（Vehicle State Monitoring）

### 1.3 親要件との対応

本文書は、親文書 ADT-REQ-MASTER-001 の以下要件を詳細化する：

- REQ-FUNC-030 ~ 032（車両制御）

## 2. システム概要

### 2.1 制御アーキテクチャ

車両制御サブシステムは、以下の制御ループで構成される：

```
目標経路・速度（経路計画）
    ↓
[横方向制御]        [縦方向制御]
操舵角指令 ←→ CAN ←→ 速度・加速度指令
    ↓                    ↓
操舵ECU              パワートレインECU
                     ブレーキECU
    ↓                    ↓
実操舵角             実速度・加速度
    ↓                    ↓
車両フィードバック（センサー）
```

### 2.2 制御周期

**VCTRL-REQ-001: 制御周期**
- 操舵制御周期：30ms  ← ★矛盾：マスターでは20ms
- 速度制御周期：30ms
- ブレーキ制御周期：15ms
- 車両状態監視周期：20ms
- 優先度：最高

### 2.3 車両動特性パラメータ

**VCTRL-REQ-002: 車両パラメータ**
- システムは、以下の車両動特性パラメータを管理しなければならない
- 車両パラメータ：
  - ホイールベース：4.5m
  - トレッド（前/後）：2.4m / 2.2m
  - 最小回転半径：12.0m
  - 車両重量：28トン（空荷） / 90トン（満載）
  - 重心高さ：2.5m（空荷） / 3.2m（満載）
  - ヨー慣性モーメント：150,000 kg·m²（空荷） / 280,000 kg·m²（満載）
- 優先度：高

## 3. 機能要件

### 3.1 操舵制御機能

#### 3.1.1 経路追従制御

**VCTRL-REQ-100: 経路追従制御アルゴリズム**
- システムは、以下のいずれかの制御手法で経路追従を実行しなければならない
  - Pure Pursuit制御
  - Stanley制御
  - Model Predictive Control (MPC)
  - LQR (Linear Quadratic Regulator)
- 優先度：高

**VCTRL-REQ-101: 前方注視距離**
- Pure Pursuit制御を使用する場合、前方注視距離は速度に応じて調整しなければならない
- 計算式：L_d = K × V + L_min
  - L_d: 前方注視距離 [m]
  - K: ゲイン（調整パラメータ、標準値0.5）
  - V: 車両速度 [m/s]
  - L_min: 最小前方注視距離 5m
- 優先度：中

**VCTRL-REQ-102: 経路追従精度**
- 経路追従の横方向誤差は、以下を満たさなければならない
  - 直線路：±40cm以内（95%信頼区間）
  - カーブ路：±70cm以内（95%信頼区間）
- 優先度：高

← ★注：経路計画では±50cm/±80cmだったので微妙に異なる

**VCTRL-REQ-103: 操舵角指令値計算**
- システムは、目標経路に追従するための操舵角指令値を計算しなければならない
- 出力範囲：±600度（左右各3回転相当）
- 分解能：0.1度
- 優先度：高

#### 3.1.2 操舵制約

**VCTRL-REQ-110: 最大操舵角制限**
- システムは、車両の最大操舵角制限を適用しなければならない
- 最大操舵角：±45度（タイヤ角）、±600度（ステアリングホイール角）
- ステアリングギヤ比：13.3:1
- 優先度：高

**VCTRL-REQ-111: 操舵角速度制限**
- システムは、操舵角速度の制限を適用しなければならない
- 最大操舵角速度：150度/秒（ステアリングホイール角）
- 優先度：高

← ★ヌケモレ：急激な操舵による横転リスク評価が未記載

**VCTRL-REQ-112: 速度依存操舵ゲイン**
- システムは、車両速度に応じて操舵制御ゲインを調整しなければならない
- 低速（10km/h以下）：高ゲイン（俊敏な応答）
- 中速（10~30km/h）：標準ゲイン
- 高速（30km/h以上）：低ゲイン（安定性重視）
- 優先度：中

#### 3.1.3 操舵系故障対応

**VCTRL-REQ-120: 操舵ECU通信異常検出**
- システムは、操舵ECUとの通信異常を検出しなければならない
- 検出条件：100ms以上メッセージ受信なし
- 検出時動作：緊急停止
- 優先度：最高

**VCTRL-REQ-121: 操舵角フィードバック異常検出**
- システムは、操舵角フィードバック値の異常を検出しなければならない
- 異常条件：
  - 指令値とフィードバック値の乖離が10度以上、1秒継続
  - フィードバック値がフリーズ（100ms以上更新なし）
- 検出時動作：緊急停止
- 優先度：最高

← ★ヌケモレ：操舵系冗長化の有無、フェールオーバー手順が未記載

### 3.2 速度制御機能

#### 3.2.1 速度追従制御

**VCTRL-REQ-200: 速度制御アルゴリズム**
- システムは、PID制御により目標速度に追従しなければならない
- PIDゲイン：
  - Kp（比例ゲイン）：積載状態に応じて調整
  - Ki（積分ゲイン）：定常偏差除去
  - Kd（微分ゲイン）：オーバーシュート抑制
- 優先度：高

**VCTRL-REQ-201: 速度追従精度**
- 速度追従精度は、±2.5km/h以内でなければならない
- 優先度：高

← ★矛盾：マスターでは±2km/h、経路計画では±3km/h

**VCTRL-REQ-202: アクセル指令値計算**
- システムは、目標加速度を実現するアクセル開度を計算しなければならない
- 出力範囲：0~100%
- 分解能：0.1%
- 優先度：高

**VCTRL-REQ-203: 勾配補償制御**
- システムは、登坂・降坂時の重力による加速度を補償しなければならない
- 勾配推定：IMU縦加速度から推定
- 補償範囲：±15度の勾配
- 優先度：高

#### 3.2.2 加速度制限

**VCTRL-REQ-210: 加速度制限値**
- システムは、以下の加速度制限を適用しなければならない
- 加速度制限：
  - 最大加速度：1.2m/s²（空荷） / 0.8m/s²（満載）
  - 最大減速度：2.0m/s²（空荷） / 1.5m/s²（満載）
  - 最大加加速度（Jerk）：0.8m/s³
- 優先度：高

**VCTRL-REQ-211: 積載状態判定**
- システムは、車両の積載状態（空荷/満載）を判定しなければならない
- 判定方法：車両重量センサー、またはサスペンション圧力センサー
- 判定閾値：50トン（50トン以上で満載判定）
- 優先度：高

#### 3.2.3 パワートレイン制御

**VCTRL-REQ-220: エンジン回転数制御**
- システムは、燃費効率を考慮したエンジン回転数制御を実行しなければならない
- 目標回転数範囲：1200~1800rpm（効率的領域）
- 優先度：中

**VCTRL-REQ-221: トランスミッション制御**
- システムは、車速と負荷に応じて適切なギアを選択しなければならない
- ギア選択ロジック：
  - 加速時：高トルク重視
  - 定速走行時：燃費重視
  - 減速時：エンジンブレーキ活用
- 優先度：中

### 3.3 ブレーキ制御機能

#### 3.3.1 通常ブレーキ制御

**VCTRL-REQ-300: ブレーキ指令値計算**
- システムは、目標減速度を実現するブレーキ圧力を計算しなければならない
- 出力範囲：0~10MPa
- 分解能：0.01MPa
- 優先度：高

**VCTRL-REQ-301: ブレーキ配分制御**
- システムは、前後輪のブレーキ力配分を最適化しなければならない
- 配分比：前輪60% / 後輪40%（標準）
- 積載状態による調整：満載時は後輪比率を増加
- 優先度：高

**VCTRL-REQ-302: アンチロックブレーキ（ABS）連携**
- システムは、車両ABS機能と連携しなければならない
- ABS作動時は、ブレーキ圧指令値を一時的に低減
- 優先度：高

#### 3.3.2 緊急ブレーキ制御

**VCTRL-REQ-310: 緊急ブレーキ作動条件**
- システムは、以下の条件で緊急ブレーキを作動しなければならない
  - 安全監視システムからの緊急停止要求
  - 前方障害物との衝突予測時間（TTC）が2秒以下
  - 操舵系・速度制御系の重大故障検出時
- 優先度：最高

**VCTRL-REQ-311: 緊急ブレーキ減速度**
- 緊急ブレーキ時の目標減速度は、以下でなければならない
  - 空荷時：4.0m/s²
  - 満載時：2.5m/s²
- 優先度：最高

**VCTRL-REQ-312: 緊急停止距離**
- 緊急ブレーキによる停止距離は、以下を満たさなければならない
  - 最大速度40km/hから：25m以内  ← ★矛盾：マスターでは15m以内
- 優先度：最高

**VCTRL-REQ-313: パーキングブレーキ自動作動**
- システムは、完全停止後にパーキングブレーキを自動作動しなければならない
- 作動条件：車速0km/hが3秒継続
- 優先度：高

#### 3.3.3 リターダー・エンジンブレーキ制御

**VCTRL-REQ-320: リターダー活用**
- システムは、長距離降坂時にリターダー（排気ブレーキ）を活用しなければならない
- 作動条件：降坂勾配5度以上、速度20km/h以上
- 優先度：中

**VCTRL-REQ-321: エンジンブレーキ活用**
- システムは、減速時にエンジンブレーキを積極的に活用しなければならない
- トランスミッションのシフトダウンにより実現
- 優先度：中

### 3.4 統合制御機能

#### 3.4.1 横滑り防止制御

**VCTRL-REQ-400: 横滑り検出**
- システムは、車両の横滑り（オーバーステア/アンダーステア）を検出しなければならない
- 検出方法：目標ヨーレートと実ヨーレートの乖離監視
- 検出閾値：乖離が5deg/s以上
- 優先度：高

**VCTRL-REQ-401: 横滑り抑制制御**
- システムは、横滑り検出時に以下の制御を実行しなければならない
  - 速度低減（減速指令）
  - 操舵補正（アンダーステア時）
  - 個別輪ブレーキ制御（車両姿勢安定化）
- 優先度：高

#### 3.4.2 横転防止制御

**VCTRL-REQ-410: 横転リスク評価**
- システムは、車両の横転リスクを評価しなければならない
- 評価指標：横加速度、ロール角、ロール角速度
- リスクレベル：低/中/高
- 優先度：高

**VCTRL-REQ-411: 横転防止介入**
- システムは、横転リスク「高」判定時に以下の介入を実行しなければならない
  - 速度強制低減
  - カーブ進入速度制限
  - 急操舵の抑制
- 優先度：最高

← ★ヌケモレ：横転リスク評価の具体的な閾値が未記載

### 3.5 車両状態監視機能

**VCTRL-REQ-500: 車両状態情報収集**
- システムは、以下の車両状態情報をCANバスから収集しなければならない
  - 車輪速度（4輪）
  - 操舵角
  - ヨーレート
  - 横加速度
  - 縦加速度
  - エンジン回転数
  - トランスミッションギア位置
  - ブレーキ圧力
  - アクセル開度
  - 燃料残量
  - 冷却水温度
  - エンジンオイル圧力
- 更新周期：20ms
- 優先度：高

**VCTRL-REQ-501: 車両状態異常検出**
- システムは、車両状態の異常を検出しなければならない
- 異常検出項目：
  - 車輪速度の異常な乖離（スリップ・ロック）
  - エンジン過熱（冷却水温度105℃以上）
  - エンジンオイル圧力低下
  - ブレーキ圧力異常
- 検出時動作：警告出力、必要に応じて緊急停止
- 優先度：高

## 4. 性能要件

### 4.1 制御応答性能

**VCTRL-REQ-600: 操舵応答時間**
- 操舵角指令から実操舵角到達までの応答時間は、200ms以内でなければならない
- 優先度：高

**VCTRL-REQ-601: 加速応答時間**
- アクセル指令から目標加速度到達までの応答時間は、500ms以内でなければならない
- 優先度：中

**VCTRL-REQ-602: ブレーキ応答時間**
- ブレーキ指令から制動力発生までの応答時間は、150ms以内でなければならない
- 優先度：高

### 4.2 制御精度

**VCTRL-REQ-610: 操舵角制御精度**
- 操舵角指令値と実操舵角の誤差は、±2度以内でなければならない
- 優先度：高

**VCTRL-REQ-611: 速度制御精度**
- 目標速度と実速度の誤差は、±2.5km/h以内でなければならない
- 優先度：高

**VCTRL-REQ-612: ブレーキ圧制御精度**
- ブレーキ圧指令値と実ブレーキ圧の誤差は、±0.2MPa以内でなければならない
- 優先度：中

## 5. 非機能要件

### 5.1 安全性要件

**VCTRL-REQ-700: 安全度水準**
- 車両制御機能は、ASIL-D相当の安全度を満たさなければならない
- 適用規格：ISO 26262
- 優先度：最高

**VCTRL-REQ-701: フェイルセーフ設計**
- 制御系の故障時、システムは安全な状態に遷移しなければならない
- 安全状態：緊急停止、パーキングブレーキ作動
- 優先度：最高

← ★ヌケモレ：具体的なフェイルセーフ動作フロー、冗長化の有無が未記載

**VCTRL-REQ-702: 制御権限管理**
- システムは、自動制御と手動制御の権限を明確に管理しなければならない
- 優先度：最高

← ★ヌケモレ：手動モードへの切り替え条件・手順が未記載

**VCTRL-REQ-703: 制御介入の可視化**
- システムは、自動制御の介入（速度制限、操舵補正など）をHMIに通知しなければならない
- 優先度：高

### 5.2 信頼性要件

**VCTRL-REQ-710: 制御安定性**
- 制御系は、外乱（路面凹凸、横風など）に対して安定でなければならない
- 検証方法：周波数応答解析、実車試験
- 優先度：高

**VCTRL-REQ-711: 制御パラメータロバスト性**
- 制御パラメータは、車両個体差や経年劣化に対してロバストでなければならない
- 優先度：中

## 6. インターフェース要件

### 6.1 入力インターフェース

**VCTRL-REQ-800: 目標経路入力IF**

- プロトコル：ROS 2 Topic
- トピック名：`/planning/trajectory`
- データ型：`custom_msgs/Trajectory`
- 更新周期：10Hz
- 優先度：高

**VCTRL-REQ-801: 目標速度入力IF**
- 経路計画サブシステムからの目標速度入力IF
- プロトコル：ROS 2 Topic
- トピック名：`/planning/velocity_profile`
- データ型：`custom_msgs/VelocityProfile`
- 更新周期：50Hz
- 優先度：高

**VCTRL-REQ-802: 自己位置入力IF**
- センシングサブシステムからの自己位置入力IF
- プロトコル：ROS 2 Topic
- トピック名：`/sensing/localization/pose`
- データ型：`geometry_msgs/PoseWithCovarianceStamped`
- 更新周期：50Hz
- 優先度：高

**VCTRL-REQ-803: 緊急停止要求入力IF**
- 安全監視サブシステムからの緊急停止要求入力IF
- プロトコル：ROS 2 Topic（高優先度）
- トピック名：`/safety/emergency_stop`
- データ型：`std_msgs/Bool`
- 優先度：最高

### 6.2 出力インターフェース

**VCTRL-REQ-810: 操舵角指令出力IF**
- 操舵ECUへの操舵角指令出力IF
- プロトコル：CAN
- メッセージID：0x200
- データ長：8 bytes
- 送信周期：30ms
- 優先度：最高

**VCTRL-REQ-811: アクセル指令出力IF**
- パワートレインECUへのアクセル指令出力IF
- プロトコル：CAN
- メッセージID：0x210
- データ長：8 bytes
- 送信周期：30ms
- 優先度：高

**VCTRL-REQ-812: ブレーキ指令出力IF**
- ブレーキECUへのブレーキ圧指令出力IF
- プロトコル：CAN
- メッセージID：0x220
- データ長：8 bytes
- 送信周期：15ms
- 優先度：最高

**VCTRL-REQ-813: 車両状態出力IF**
- HMI・運行管理システムへの車両状態出力IF
- プロトコル：ROS 2 Topic

- 更新周期：10Hz
- 優先度：中
