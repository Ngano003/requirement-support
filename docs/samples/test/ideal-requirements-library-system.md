# 社内図書管理システム 要件定義書

## 1. システム概要

### 1.1 プロジェクト名
社内図書管理システム

### 1.2 目的・背景
現在、社内の書籍や資料の管理が紙ベースで行われており、以下の課題がある：
- 貸出中の本の把握が困難
- 借りている社員の追跡ができない
- 在庫管理が煩雑
- 予約機能がない

これらの課題を解決し、効率的な図書管理を実現するため、Webベースの図書管理システムを開発する。

### 1.3 対象ユーザー
- **一般ユーザー**: 全社員（約200名）
- **管理者**: 図書管理担当者（総務部2名）

## 2. 目的と期待効果

### 2.1 目的
- 図書の貸出・返却業務の効率化
- 在庫状況のリアルタイム把握
- 社員の利便性向上

### 2.2 期待効果
- 図書管理業務の工数削減
- 本の所在不明・紛失の防止
- 社員の読書環境の改善

## 3. 機能要件

### 3.1 社員向け機能

#### 3.1.1 書籍検索機能
- **機能概要**: 蔵書を検索できる
- **検索条件**:
  - タイトル（部分一致）
  - 著者名（部分一致）
  - カテゴリ
  - ISBN
- **検索結果表示**:
  - 書籍の基本情報（タイトル、著者、出版社、ISBN、カテゴリ）
  - 貸出状況（貸出可能、貸出中、予約中）
  - 返却予定日（貸出中の場合）

#### 3.1.2 書籍予約機能
- **機能概要**: 貸出中の書籍を予約できる
- **処理フロー**:
  1. 貸出中の書籍を選択
  2. 予約ボタンをクリック
  3. 予約完了通知を表示
- **制約**:
  - 同一書籍に対して1人1予約まで
  - 予約待ち人数の上限: **TODO（要確認）**

#### 3.1.3 貸出履歴確認機能
- **機能概要**: 自分の貸出履歴を確認できる
- **表示項目**:
  - 現在借りている本のリスト
  - 貸出日
  - 返却期限日
  - 延滞状況（返却期限超過の場合）
  - 過去の貸出履歴（直近1年分）

#### 3.1.4 返却期限リマインド通知
- **機能概要**: 返却期限が近づいたらメール通知
- **通知タイミング**: 返却期限の**TODO（3日前？要確認）**
- **通知内容**:
  - 書籍タイトル
  - 返却期限日
  - 延長可能回数

### 3.2 管理者向け機能

#### 3.2.1 書籍登録機能
- **機能概要**: 新しい書籍を登録する
- **入力項目**:
  - ISBN（必須）
  - タイトル（必須）
  - 著者（必須）
  - 出版社
  - 出版年
  - カテゴリ（ドロップダウン選択）
  - バーコード番号
  - 配架場所
  - 備考
- **ISBN自動取得機能**:
  - ISBNを入力すると、外部API経由で書籍情報を自動取得
  - 取得した情報は編集可能

#### 3.2.2 書籍編集・削除機能
- **編集**: 書籍情報を更新できる
- **削除**:
  - 貸出中でない書籍のみ削除可能
  - 削除時に確認ダイアログを表示

#### 3.2.3 貸出処理機能
- **機能概要**: バーコードリーダーで書籍と社員証をスキャンして貸出処理
- **処理フロー**:
  1. 書籍バーコードをスキャン
  2. 社員証バーコードをスキャン
  3. 貸出確認画面を表示（書籍情報、社員名、返却期限日）
  4. 確定ボタンで貸出完了
- **貸出制限**:
  - 1人あたりの貸出上限: **TODO（5冊？要確認）**
  - 貸出期間: 2週間
  - 延滞中の書籍がある場合は新規貸出不可

#### 3.2.4 返却処理機能
- **機能概要**: バーコードリーダーで返却処理
- **処理フロー**:
  1. 書籍バーコードをスキャン
  2. 返却確認画面を表示
  3. 確定ボタンで返却完了
- **延滞処理**:
  - 延滞日数を表示
  - 延滞ペナルティ: **TODO（延滞料金は設ける？要確認）**

#### 3.2.5 貸出延長機能
- **機能概要**: 返却期限を延長する
- **延長条件**:
  - 延長可能回数: 1回まで
  - 延長期間: 2週間
  - 予約が入っている場合は延長不可

#### 3.2.6 在庫管理機能
- **機能概要**: 蔵書の在庫状況を一覧表示
- **表示項目**:
  - 全書籍リスト
  - 貸出状況（貸出可能、貸出中）
  - 貸出中の場合: 借りている社員名、返却期限日
- **フィルタ機能**:
  - カテゴリ別
  - 貸出状況別
  - 延滞のみ表示

#### 3.2.7 レポート出力機能
- **機能概要**: 統計情報をCSVまたはPDF形式で出力
- **レポート種類**:
  - 貸出ランキング（人気の書籍トップ10）
  - 社員別貸出回数
  - カテゴリ別貸出統計
  - 延滞リスト
  - 期間指定での貸出集計

### 3.3 共通機能

#### 3.3.1 ログイン・認証機能
- **認証方式**: 既存の社内認証システムと連携（SSO）
- **権限管理**:
  - 一般ユーザー: 検索、予約、自分の履歴確認のみ
  - 管理者: すべての機能にアクセス可能

#### 3.3.2 通知機能
- **メール通知**:
  - 返却期限リマインド
  - 延滞通知（返却期限超過時）
  - 予約書籍の貸出可能通知
  - 督促メール（延滞が**TODO（1週間以上？要確認）**続いた場合）

## 9. データモデル（概要）

### 9.1 主要エンティティ
- **書籍（Book）**: ISBN、タイトル、著者、出版社、カテゴリ、バーコード等

- **予約（Reservation）**: 予約ID、書籍ID、社員ID、予約日
