# ヌケモレ (ISレイヤー):

ACT-002 (MaintenanceCrew) が定義されていますが、どの Function にも USES でリンクしていません。（孤立したアクター）

CONST-S-001 (緊急停止) は Function に適用されていますが、HW-002 (Lidar) に APPLIES_TO されていません。Lidar 自体への安全制約（例：Lidar故障時の動作）が考慮されていません。

FUNC-002 (物品ピックアップ) が DEPENDS_ON で FUNC-001 (棚Aへ移動) とリンクしていません。グラフ上、独立してピックアップできてしまいます。

# 矛盾 (SHOULD vs SHOULD):

内部矛盾: CONST-P-001 は移動機能の最大速度を 1.0 m/s と定義しています。しかし CONST-P-003 は（おそらくピックアップ中を意図していますが、書き方では）同じ移動機能の速度を 0.1 m/s を超えてはならない、と定義しています。

検出方法: Constraint 2つが、同一の対象（FUNC-001など）に対して競合する value を持っていることをハイブリッド検出（LLMによる論理判断）で検出します。
